# Лабораторні роботи з дисципліни «Технології високопродуктивних обчислень»

## Мета курсу

Ознайомлення з принципами високопродуктивної обробки даних, технологіями паралельного та розподіленого програмування, методами оптимізації й оцінювання продуктивності обчислювальних алгоритмів.

## Перелік лабораторних робіт

### Лабораторна робота №1. Введення у технології високопродуктивної обробки даних

Вивчення архітектури обчислювальних систем і класифікації Флінна. Реалізація послідовної програми мовою C++ та вимірювання часу її виконання.

### Лабораторна робота №2. Введення у OpenMP

Реалізація паралельного алгоритму мовою C++ із використанням OpenMP. Порівняння продуктивності послідовної та паралельної реалізацій.

### Лабораторна робота №3. Оптимізація паралельних алгоритмів у OpenMP

Дослідження стратегій планування `static`, `dynamic` і `guided`. Порівняння їхнього впливу на продуктивність паралельних обчислень.

### Лабораторна робота №4. Організація багатопотокових обчислень мовою C++

Реалізація багатопотокового алгоритму з використанням засобів C++. Дослідження впливу кількості потоків на час виконання обчислень.

### Лабораторна робота №5. Організація паралельних обчислень мовою C# з використанням бібліотеки TPL

Реалізація паралельного алгоритму засобами `Parallel.For` або `Parallel.ForEach`. Дослідження продуктивності за різної кількості потоків.

### Лабораторна робота №6. Профілювання паралельних програм у Visual Studio Concurrency Visualizer

Профілювання послідовної та паралельної програм. Аналіз завантаження процесорних ядер, потоків і використання обчислювальних ресурсів.

### Лабораторна робота №7. Організація GPGPU-обчислень

Реалізація паралельного алгоритму на графічному процесорі з використанням NVIDIA CUDA або AMD ROCm. Порівняння продуктивності CPU- та GPU-реалізацій.

### Лабораторна робота №8. Організація розподілених обчислень у вузлах локальних мереж

Розроблення системи розподілених обчислень на основі ASP.NET Core. Реалізація сервера-диспетчера та клієнтів-обчислювачів, передавання завдань через HTTP і дослідження масштабованості системи.

## Основні технології

- **C++** — послідовне, багатопотокове та паралельне програмування.
- **OpenMP** — організація паралельних обчислень.
- **std::thread** — багатопотокове програмування мовою C++.
- **C# / .NET** — розроблення паралельних застосунків.
- **TPL** — бібліотека паралельних обчислень .NET.
- **Visual Studio Concurrency Visualizer** — профілювання паралельних програм.
- **NVIDIA CUDA / AMD ROCm** — GPGPU-обчислення.
- **ASP.NET Core** — організація розподілених обчислень.

## Результати навчання

У результаті виконання лабораторних робіт здобувачі набувають практичних навичок:

- розроблення та оптимізації обчислювальних алгоритмів;
- використання багатопотокового і паралельного програмування;
- застосування CPU- та GPU-ресурсів для прискорення обчислень;
- профілювання та аналізу продуктивності програм;
- організації розподілених обчислень;
- оцінювання прискорення та ефективності паралельних систем.
